# Roblox Scripts

Roblox Scripts are custom scripts designed to enhance the functionality and interactivity of Roblox games. These scripts can be used to create triggers, spawn objects, control game mechanics, and more. They are written in Lua and can be easily integrated into Roblox Studio.

## Install

1. Open Roblox Studio.
2. Create a new script or open an existing one.
3. Copy and paste the script code into the script editor.
4. Save the script.

## Use

1. Place the script inside a `Script` object in the Roblox Studio hierarchy.
2. Ensure the `Script` object is a child of the object that will act as the trigger (e.g., a `Part` or `Model`).
3. Run the game in Roblox Studio to test the script.
